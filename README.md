# Xin

Xin 是一个安卓剪贴板管理应用：自动记住你复制过的文字，随时搜索、收藏、再次复制。
功能和交互参考了 iOS 上的 Pin，代码、名字、图标和配色都是 Xin 自己的。

## 第一版（0.1.0）能做什么

| 功能 | 说明 |
| --- | --- |
| 自动收录 | 每次回到 Xin，自动把剪贴板里的新文字存进历史；重复内容只会移到最前 |
| 快捷设置磁贴 | 在下拉菜单添加“存剪贴板”磁贴，不打开 Xin 也能一键收录 |
| 分享 / 选中文字 | 其他应用里“分享 → 存到 Xin”，或长按选中文字后点“存到 Xin” |
| 历史列表 | 点一下复制；左滑删除（可撤销）；长按弹出更多操作 |
| 收藏 | 点图钉收藏，收藏的内容不会被清空，也不受 500 条上限影响 |
| 分类 | 全部 / 收藏 / 链接；自动识别链接、电话、邮箱，可直接打开、拨号、发邮件 |
| 搜索 | 按内容搜索，匹配的文字会高亮 |
| 新建和编辑 | 手动添加或修改一条内容 |
| 桌面快捷方式 | 长按图标：新建、搜索；也支持 `xin://new`、`xin://search` |
| 深色模式 | 跟随系统 |

## 和 Pin 的功能对照

| Pin（iOS） | Xin 现状 | 安卓上的做法 |
| --- | --- | --- |
| 剪贴板历史、收藏、链接分类 | ✅ 已完成 | Room 数据库 |
| 3D Touch 快捷操作（新建、搜索、清空） | ✅ 新建、搜索 | App Shortcuts；“清空未收藏”放在菜单里，需要确认 |
| Action 扩展（分享到 Pin） | ✅ 已完成 | 分享目标 + 文字选择菜单 |
| Today 小组件 | 计划中 | Glance 桌面小组件，显示最近几条，点击复制 |
| 自定义键盘 PinKey | 计划中 | 输入法服务（IME）。默认输入法可以在后台读剪贴板，是安卓上真正“全自动收录”的唯一正规途径 |
| Spotlight 搜索 | 计划中 | 桌面快捷方式 / 系统搜索 |
| 图片、GIF 收藏 | 计划中 | 存文件 + 缩略图 |
| iCloud 同步 | 计划中 | 导入导出 JSON，之后再考虑 WebDAV |
| JSBox 风格的 JS 扩展 | 以后再说 | 工作量大，等核心功能稳定后评估 |

## 安卓的剪贴板限制

安卓 10 开始，只有前台应用和当前输入法能读取剪贴板，后台服务读不到。所以 Xin 用三种方式收录：
回到 Xin 时自动读取、快捷设置磁贴（拉起一个透明页读取后立即关闭）、分享和文字选择菜单。
安卓 13 以上读取剪贴板时系统会弹出“Xin 已粘贴”的提示，这是系统行为。

## 构建

- 需要 Android Studio（Ladybug 或更新）或 JDK 17 + Android SDK 35
- 命令行：`./gradlew :app:assembleDebug`，APK 在 `app/build/outputs/apk/debug/`
- 推到 GitHub 后，`.github/workflows/android.yml` 会自动构建并把 APK 作为 Actions 产物上传

技术栈：Kotlin 2.0、Jetpack Compose（Material 3）、Room、AGP 8.7、minSdk 26、targetSdk 35。

## 目录

```
app/src/main/java/com/xiaokuaile/xin/
  XinApp.kt                 应用入口，持有数据仓库
  data/                     Room 实体、DAO、数据库、仓库（去重、上限、合并）
  clipboard/                读写系统剪贴板，跳过标记为敏感的内容（如密码）
  entry/                    分享接收页、透明收录页、快捷设置磁贴
  ui/                       主界面、列表、操作面板、编辑对话框、主题
```
